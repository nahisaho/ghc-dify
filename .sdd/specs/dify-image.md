## Design
Digest-pinned Trixie agent base + relocated agent venv + intact official API; copied Next web uses glibc Node/Sharp overlay. PostgreSQL17.11/pgvector0.8.0, Redis8.0.2, plugin0.6.14-local, sandbox0.2.15, shellctl1.19.0 and nginx/Squid/sshd/tini-supervisor remain required. Bootstrap /data private per-consumer secrets and root-owned SSH hostkeys (0700 directories/0600 files, umask077, no symlinks) -> PostgreSQL/Redis -> migrations -> auxiliaries -> API/worker/beat/web -> all-role readiness (300s deadline). Runtime secrets never enter dev-home; dev owns only its 0700 Copilot home/workspace. sshd uses AllowUsers dev, PermitRootLogin no, PasswordAuthentication no, KbdInteractiveAuthentication no, AuthenticationMethods publickey, StrictModes yes and a root-owned validated copy of the separate read-only authorized_keys mount.
One shared network/PID namespace gives UID/DAC and chroot/seccomp job boundaries, not per-service networking/forced egress, hostile-plugin containment or port ownership; DB/Redis authenticate and proxies are cooperative. Distinct nonroot services use UIDs below10000 excluding dev2000; reserve GID1000 for pooled job UIDs>=10000 only; supplementary service groups and operative capabilities are absent. Jobs get sanitized env, no secret mounts/FDs, private roots and no-new-privileges. Root exceptions: bounded provisioning/sshd supervision AND a trusted sandbox broker/launcher with only CHOWN,SETUID,SETGID,SYS_CHROOT operative caps; this broker can access root secrets and is TCB, not a proven tiny helper. Normalize bundled Node20.20.0 ownership in a sandbox-private path, never replacing shared Node24; consume a trusted root-owned, never job-writable Python bootstrap through a preopened FD/stdin before the job UID switch, preserving user-code FD3. Disable preload, runtime package installation and dependency mutation/refresh routes IN the broker, not merely a proxy; expose only health and authenticated run/read-only dependency queries; reap every job process before UID reuse. Container cap-drop ALL ceiling remains CHOWN,FOWNER,SETUID,SETGID,KILL,SYS_CHROOT; child bounding bits may remain but job CapInh/Prm/Eff/Amb=0 and NoNewPrivs=1 prevent regain. Namespace-local net.ipv4.ip_unprivileged_port_start=0 permits ALL nonroot roles to bind80/22 without NET_BIND_SERVICE (spike: UID2000 bind80 succeeds at0 and EACCES at1024); actual nginx remains unrun. No SYS_ADMIN/NET_ADMIN/SYS_PTRACE/DAC_OVERRIDE/DAC_READ_SEARCH, privileged mode, host network/socket/broad mounts or generic privileged user-code execution.
